What exists todayAngularJS 1.8.3 + jQuery + Bootstrap 3.4.1 (Bootswatch spacelab / darkly). Seven menu pages plus two detail pages, all plain tables. No charts. Theme: light / dark button; device is only the fallback before a choice is stored.
Constraints I assume stayServed from the jar by the web admin filter · Maven-only build (no Node) · CSP default-src 'self', no inline or eval'd scripts · nothing loaded from another host · CSRF meta tags keep working.
Vendored today11 npm packages, about 940 KB under webadmin/vendor/. AngularJS (end of life since January 2022) and Bootstrap 3 (end of life since 2019) no longer get security fixes.
Data available for charts/metrics: per-job success / failure counters and duration mean / max — per instance, reset on restart. /log: paged rows only, each carrying its full stack trace. No time-series endpoint.

Noticed while reading (not part of the questions)

  • webadmin/inc/timeline.html is not routed in app.js and nothing loads it; style.css carries minified timeline CSS pointing at /images/16/*.png files that do not exist. The README still lists a "Timeline" page. A rewrite would drop these; a re-skin (Q1 option C) would leave them unless you say otherwise.
  • The Executions list downloads every row's stack trace and job data (up to ~10 KB each) just to show their byte count; at page size 500 that is several MB per refresh.
  • Dates are formatted with hh (12-hour clock) without AM/PM, so 14:05 and 02:05 look the same.
  • "Cluster nodes" is removed from the menu only after the Scheduler page has been opened once.
